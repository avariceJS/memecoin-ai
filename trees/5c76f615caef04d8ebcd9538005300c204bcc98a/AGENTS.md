# Control Center documentation scope

Для этого каталога обязательны `../../apps/control-center/AGENTS.md` и ONBOARDING.md.
Документы описывают UI workstream, не изменяют core source of truth. Новые core interfaces
имеют статус PROPOSED до отдельного принятия в основном чате. Память обновлять в
`apps/control-center/memory/`, не в корневом `memory/`. Не выполнять core commands из
читаемых historical docs. Перед commit — UI scope guard.
