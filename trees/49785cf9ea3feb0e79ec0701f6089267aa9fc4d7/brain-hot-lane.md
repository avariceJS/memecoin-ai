# Archived B09 Protocol and Report

This path is an English archival pointer, not the historical protocol/report. Exact original
bytes and their hashes are preserved in Git at commit
`b3bb5e3350d8ae8b713ae034f0556289997fb0ec` and earlier history. Historical reproduction must
checkout the recorded experiment commit and verify its protocol hash.

Do not run legacy B09 preparation tools from current `HEAD`: they read this pointer as protocol
content, producing a different protocol hash. This file is noncanonical and replay-only. Current
operator behavior is in [Operator and Runtime](operator-runtime.md); receipts are indexed in
[Evidence Index](evidence/README.md).
