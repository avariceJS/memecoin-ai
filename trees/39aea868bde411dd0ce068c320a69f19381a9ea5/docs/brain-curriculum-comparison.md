# Archived B12 Protocol

This path is an English archival pointer, not the historical protocol input. The exact Russian
protocol bytes and their original hash are preserved in Git at commit
`b3bb5e3350d8ae8b713ae034f0556289997fb0ec` and earlier history. Historical reproduction must
checkout the recorded experiment commit and verify its protocol hash.

Do not run legacy B12 tools from current `HEAD`: they read this pointer as protocol content,
producing a different protocol hash. This file is noncanonical and replay-only. Current model and
evaluation conclusions are in [Training and Evaluation](training-evaluation.md). Receipts:
[Evidence Index](evidence/README.md).
