# Optional Control Center roles

Current user/session instructions and apps/control-center/AGENTS.md govern delegation.
No model is forced by the six role definitions; Grok remains disabled. Select helpers only when
useful and authorized. Model configuration/self-report never proves observed execution.

- artifact-analyst: read-only bounded projection/receipt inventory, no raw artifact traversal.
- ui-builder: assigned web files, preserve semantic/availability contracts.
- adapter-builder: assigned adapter/contracts files, no new unreviewed sources or controls.
- test-debugger: assigned tests, no weakening gates to obtain PASS.
- visual-reviewer: read-only actual target/before/current screenshots and acceptance rubric.
- boundary-reviewer: read-only IO/provenance/protected-data/origin/verb review.

Integrator owns Git, shared package locks and WORK_STATE. Give each helper explicit read/write
files, task, expected output and current constraints. Avoid overlapping writers and nested
agents. Do not send credentials, raw protected data or unrestricted repository inventories.
For visual work each reviewer must inspect images personally; require actual browser captures,
fix/second capture, layout matrix and independent critique before acceptance. Return concise
findings and verified checks, including limitations. The historical CC02 task graph remains.
