# Текущий статус

Обновлено: **2026-10-01**, пользовательская временная зона Europe/Moscow.

## Стадия

Архитектурный проход в работе. Пользователь принял Memory Bank как source of truth и разрешил автономную реализацию фундамента, проверки, коммиты и push при доступной аутентификации.

## Что существует

- Папка проекта `memecoin-ai`, выбранная пользователем в проектах Codex.
- Memory Bank из связанных Markdown-документов, точка входа `AGENTS.md` и корневой README.
- Реестр D01–D17 и план E01–E14.
- История пересмотра концепции, список открытых параметров, roadmap и источники.
- `.gitignore` для локальных данных, весов, секретов и тяжёлых артефактов.
- Git-репозиторий на `main`; origin настроен на `https://github.com/avariceJS/memecoin-ai.git`.

Результаты проверки создания фиксируются в последней записи [changes.md](changes.md). Наличие Git не подразумевает remote или публикацию. Точную историю коммитов читать из Git, не из вручную дублируемых hash в документах.

## Что не существует

Нет квалифицированного реального dataset, production collector, venue-calibrated simulator, обученной торговой модели, experiment results, benchmark M4, paper bot и live execution. Первые примитивы событий, хранения и observations реализуются в этом проходе. Ни один опыт E01–E14 не проведён. Источник данных не выбран, edge не установлен.

## Текущие выборы

Приняты: независимая от LLM PyTorch-система, point-in-time данные, реалистичное исполнение, независимый risk layer, временная оценка, необязательность RL, широкое наблюдение при ограниченном первом execution domain, версионированный retraining.

Не зафиксированы: backbone, size, scanner/K, temporal format, cross-token/graph architecture, horizons/frequency, sizing, конкретный рынок внутри Solana, провайдер, капитал, валюта primary objective, риск-пороги и promotion thresholds. Актуальные причины и сравнения — [decisions.md](decisions.md), не старые численные рекомендации из обсуждения.
