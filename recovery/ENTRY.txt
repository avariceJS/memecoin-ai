BRAIN FIRST-HOST ENTRY — CODE BOOTSTRAP ONLY

Purpose
=======
This plain-text card gets a clean compatible Mac to an authenticated, exact Git checkout
and a rebuilt inert development environment. It does not restore Brain data or private state,
start services, send provider requests, or authorize erase. A successful result is only
“code bootstrap verified.”

Trust pins
==========
Use ENTRY_COMMIT and ENTRY_SHA256 from a trusted handoff kept outside Kingston. Do not take
either pin only from this card. The handoff must identify the exact Git commit and the SHA-256
of this file at that commit. ENTRY_COMMIT is also the BOOTSTRAP_COMMIT for this procedure.

Requirements
============
1. Install a supported Git and Python 3.11 or newer using the normal macOS installer/account.
2. Attach Kingston. Do not use a similarly named volume. Before cloning, inspect it read-only:

   KINGSTON_FACTS=$(python3 -c 'import plistlib,subprocess; p=plistlib.loads(subprocess.check_output(["/usr/sbin/diskutil","info","-plist","/Volumes/Kingston"])); print("|".join(str(p.get(k,"")) for k in ("VolumeUUID","MountPoint","FilesystemType","FilesystemName")))') || exit 2
   test "$KINGSTON_FACTS" = '8f8f1081-9be4-4914-9111-75f1b90255bf|/Volumes/Kingston|apfs|Case-sensitive APFS' || exit 2
   test -d /Volumes/Kingston/BrainData && test ! -L /Volumes/Kingston/BrainData || exit 2
   test -f /Volumes/Kingston/BrainData/.research-root.json && test ! -L /Volumes/Kingston/BrainData/.research-root.json || exit 2

If any check fails, stop. Do not create a replacement root. These checks identify the mounted
volume and confirm the existing root marker is present; the later bound storage check verifies
the marker contents and ownership before any data restore.

Entry checkout
==============
Set ENTRY_COMMIT to the 40-character value from the trusted handoff. Set ENTRY_DIR to a new,
empty path; the example below uses a commit-specific path and refuses to reuse it. Git will use
the user's normal interactive account authentication. Do not put credentials in the URL, shell
history, command arguments, this card, or logs.

   ENTRY_COMMIT='<40-character trusted pin>'
   ENTRY_SHA256='<64-character trusted pin>'
   ENTRY_DIR="$HOME/brain-entry-$ENTRY_COMMIT"
   test ! -e "$ENTRY_DIR" && test ! -L "$ENTRY_DIR" || exit 2
   git clone --no-checkout -- https://github.com/avariceJS/memecoin-ai.git "$ENTRY_DIR" || exit 2
   git -C "$ENTRY_DIR" fetch --no-tags origin "$ENTRY_COMMIT" || exit 2
   git -C "$ENTRY_DIR" checkout --detach "$ENTRY_COMMIT" || exit 2
   test "$(git -C "$ENTRY_DIR" rev-parse HEAD)" = "$ENTRY_COMMIT" || exit 2
   CARD_SHA256=$(shasum -a 256 /Volumes/Kingston/BrainData/host-recovery/ENTRY.txt | cut -d ' ' -f 1)
   SOURCE_CARD_SHA256=$(shasum -a 256 "$ENTRY_DIR/recovery/ENTRY.txt" | cut -d ' ' -f 1)
   test "$CARD_SHA256" = "$ENTRY_SHA256" || exit 2
   test "$SOURCE_CARD_SHA256" = "$ENTRY_SHA256" || exit 2
   cmp -s /Volumes/Kingston/BrainData/host-recovery/ENTRY.txt "$ENTRY_DIR/recovery/ENTRY.txt" || exit 2
   test -z "$(git -C "$ENTRY_DIR" status --porcelain --untracked-files=all)" || exit 2

If Git authentication fails, stop and complete account login through the normal user-controlled
flow before trying again. Never reuse the old Mac's Keychain, tokens, or session stores. If a pin,
volume identity, card comparison, or exact checkout check fails, stop; do not continue from a
partial or different source.

Final inert checkout
====================
Choose a new absolute destination outside any existing Git checkout. The example target must not
already exist. Invoke the existing helper from the verified entry checkout; it performs a second
exact-commit clone, rebuilds the locked development environment, and runs smoke:

   FINAL_DIR="$HOME/Developer/memecoin-research"
   mkdir -p "$HOME/Developer"
   test ! -e "$FINAL_DIR" && test ! -L "$FINAL_DIR" || exit 2
   python3 "$ENTRY_DIR/tools/brain_host_recovery.py" bootstrap \
     --remote https://github.com/avariceJS/memecoin-ai.git \
     --commit "$ENTRY_COMMIT" \
     --destination "$FINAL_DIR" \
     --format json

Accept only state=complete, head equal to ENTRY_COMMIT, and smoke=passed. Also confirm
`git -C "$FINAL_DIR" rev-parse HEAD` equals ENTRY_COMMIT and the final worktree is clean.
The entry checkout and final checkout must both have that exact HEAD. If a clone, dependency
install, or smoke step fails, the result is blocked; do not infer success from a partial
environment. The helper does not activate launchd, change storage, restore data, or send requests.

Afterward
=========
Keep the entry checkout until the final checkout result has been recorded. It is a temporary,
disposable code source, not Brain state. Remove only this exact run-owned ENTRY_DIR after checking
its path and exact HEAD; never use a wildcard or broad temporary-directory cleanup. Continue with
the canonical `docs/portability-disaster-recovery.md` recovery procedure to bind Kingston and
restore state. This card never says “Brain restored” or “SAFE TO ERASE.”
